3C 분석

3C 분석 예시 — 보험상담 AI Agent × 블록체인 인슈어테크

"AI 상담으로 '상품 선택'의 마찰을, 블록체인 자동화로 '청구 신뢰'의 문제를 동시에 해결하는 이중 차별화 필요"

C

Company — 자사

  • LLM 기반 AI Agent(자율 tool-calling 루프)가 상담·상품추천 수행 + 스마트컨트랙트 자동화(청구·지급·파라메트릭보험 등) 결합
  • 언더라이팅 AI Agent 18종 도구를 스스로 판단·실행, 신용점수 서브에이전트와 이중 구조로 정밀 심사
  • 신용정보 부족(씬파일러)·건강검진 결과·최근 병력을 알려줘도 대안신용평가·유병자 요율·건강체 할인으로 맞춤 상품 자동 설계
  • 가입부터 지급까지 온체인 기록 + Slack 실시간 알림으로 운영 투명성 확보
C

Customer — 고객

  • 상품 비교·선택에 어려움을 겪는 보험 가입 희망자
  • 기존 치아보험 청구 절차(서류·대기)에 불편을 느끼는 가입자
  • 신용정보 부족(씬파일러)·지병·건강검진 이상소견 등으로 기존 채널에서 거절·고비용 안내를 받던 고객
  • 블록체인·핀테크 수용도가 높은 2030 얼리어답터

Competitor — 경쟁사

  • 보험사 다이렉트 채널 — 상담은 있으나 AI 실시간 맞춤 추천 부재
  • 보험다모아 등 공시 비교 플랫폼 — 가격 비교만 가능, 상담·가입·청구 미연계
  • 국내 블록체인 인슈어테크 — AI 상담+온체인 자동화 결합 사례 거의 전무

Strategic Position

SWOT 분석

SWOT 분석 예시 — 보험상담 AI Agent × 블록체인 인슈어테크

STRENGTHS

  • AI Agent(상담·언더라이팅 자율 수행) + 스마트컨트랙트 자동화를 모두 갖춘 통합 아키텍처
  • 청구~지급 전 과정 온체인 투명성
  • AI Agent(자율 심사 실행) × AI 어드바이저(참고용 권고)의 이중 구조 — 자동화 수준을 용도별로 설계
  • Slack 실시간 알림 + AI 어드바이저로 운영 효율화
  • USDC·원화 스테이블코인 이중 통화 구조 — 환전 없이 즉시 정산, 해외 송금 비용·시간 절감
  • 신용정보 부족(씬파일러)·건강검진 결과·병력을 알려줘도 대안신용평가·유병자 요율로 맞춤 상품 제안

WEAKNESSES

  • 스마트컨트랙트 불변성 — 로직 수정 어려움(업그레이드 프록시 미적용)
    → 보완: 담보 선택·보험료 계산 등 자주 바뀌는 로직은 프론트엔드/오프체인으로 분리, 향후 프록시 패턴 도입 검토
  • 지갑 온보딩 등 가입 진입장벽
    → 보완: 관리자 지원 온보딩 제공, 계정 추상화 기반 소셜로그인 지갑 연동 검토
  • 건강정보 등 민감정보를 AI·온체인에 노출하는 프라이버시 부담
    → 보완: AI 검토 결과는 항상 참고용(자동 승인·거절 금지), 민감정보는 로컬 LLM 폴백으로 외부 전송 최소화, 프롬프트 인젝션 가드 적용

OPPORTUNITIES

  • 인슈어테크 시장 성장 + 정부 블록체인 시범사업 지원
  • 마이데이터 연계로 개인 맞춤 추천 고도화 가능
  • 로컬 LLM 도입으로 프라이버시 강화 모델 확장 가능
  • 오라클 고도화로 완전 무인 심사 확장 여지

THREATS

  • 대형 보험사·빅테크의 유사 AI 상담 서비스 진입
    → 기회로: 실제 작동하는 "AI Agent + 온체인 자동화" 레퍼런스를 먼저 확보 — 후발주자에게 백오피스 솔루션으로 라이선스·제휴 제안 가능
  • 블록체인 관련 규제 불확실성
    → 기회로: 디지털자산 기본법 등 제도 정비 초기 단계 — 실증 사례로 규제 샌드박스·정부 시범사업 참여를 선점
  • 스마트컨트랙트 보안 감사 미비에 따른 취약점 리스크
    → 기회로: 정식 서비스 전환 시 외부 감사·오픈소스 공개를 신뢰도 입증 요소로 활용, 커뮤니티 검증 유도
  • LLM 환각(hallucination)으로 인한 상담 신뢰성 저하 우려
    → 기회로: "AI 결과는 항상 참고용" 구조 자체가 차별화 포인트 — 환각 위험을 구조적으로 통제하는 인슈어테크로 포지셔닝
강점×기회 — AI 상담과 온체인 자동화로 상품 선택부터 청구·지급까지 신뢰성 극대화
전략 방향 — "신뢰할 수 있는 인슈어테크" 포지셔닝: AI와 블록체인이 만드는 투명한 보험 경험, 스테이블코인 제도화 흐름에 올라탄 글로벌 정산 확장, 신용·병력으로 소외되던 고객까지 포용하는 맞춤형 언더라이팅

왜 블록체인 + 스테이블코인인가 — 보험 밸류체인 단계별 효과

앞의 강점·전략을 보험 처리 단계에 대입하면, 각 단계마다 기존 방식의 한계가 구체적으로 해소됩니다.

보험청약

약관·조건이 문서로만 존재해 이후 해석·변경 여지가 생김

가입 조건이 스마트컨트랙트 코드로 고정 — 청약 시점 그대로 불변 기록

보험료 지급(납입)

은행 영업시간·환전에 묶여 납입 시점이 제한됨

USDC·원화 스테이블코인으로 24/7 환전 없이 즉시 납입, 실패 시 즉시 Slack 알림

보험금 청구

서류 제출 후 영업일 단위로 수작업 심사 대기

오라클이 청구를 자동 심사, 조건 충족 시 컨트랙트가 즉시 처리

명확성

보험사만 원장을 보유해 고객은 처리 현황을 알기 어려움

청약~지급 전 이력이 온체인에 공개돼 고객·보험사가 같은 기록을 조회

일부 즉시 지급

소액·정형화된 청구도 전체 청구와 동일한 심사 대기열에 묶임

담보 조건이 명확한 청구는 사람 개입 없이 스마트컨트랙트가 즉시 (부분)지급

준비금 송금·인출

은행 송금 지연, 준비금 부족 여부를 지급 실패 후에야 확인

스테이블코인으로 준비금 즉시 입출금 + 부족 전환 시점을 워처가 사전 경보

Capability Architecture

AI Agent · AI 어드바이저 · 자동화 — 기능 분류

"자동화 수준을 용도별로 설계"(SWOT 강점) 원칙을 실제 기능 단위로 분해 — 무엇이 LLM 자율 실행이고, 무엇이 사람의 최종 승인을 거치며, 무엇이 애초에 AI가 관여하지 않는 규칙 기반 처리인지 구분

🤖

AI Agent — 자율 실행

  • 메인 상담 오케스트레이터: 상품 검색·비교·블록체인 조회 도구를 스스로 판단해 호출
  • 언더라이팅 서브에이전트: 18종 assess_* 시나리오(암 완치자 재심사~씬파일러 유연납입 적격 심사) 중 필요한 도구를 자율 선택·실행
  • 개인화 추천 서브에이전트: 연령·예산·니즈 기반 포트폴리오 자율 구성
  • 웰니스 체크인 도구: 건강개선 판정 시 온체인 보험료 할인까지 직접 실행 — 사람 승인 없이 즉시 반영되는 유일한 완전자율 액션
🧑‍⚖️

AI 어드바이저 — Human-in-the-Loop

  • 고액 청구(보장한도 20% 초과) AI 사전검토: 치료코드·금액·과거 이력을 검토해 Slack으로 의견만 전송
  • 승인·거절·지급은 관리자가 화면에서 직접 수행 — AI 산출물은 최종 의사결정에 자동 반영되지 않음
  • 환각(hallucination) 리스크를 "참고용" 구조로 원천 통제 — 틀려도 실제 자금 이동으로 이어지지 않음

Growth Roadmap

신규 사업 확장 로드맵

앞선 SWOT 전략(신뢰할 수 있는 인슈어테크 포지셔닝)을 실제 상품·서비스 5종으로 구체화

기존 인프라(오라클·언더라이팅 서브에이전트·준비금 계좌)를 재사용해 개발 비용을 최소화하면서, 각기 다른 차별점과 수익모델을 갖는 5개 확장 방향을 실제로 구현·검증함

A. 파라메트릭(자동집행) 보험

차별점: 청구 서류·심사 절차 없이 오라클이 조건(지연시간·폭염특보 발령일수) 충족 여부만 보고 즉시 자동지급 — 항공지연·폭염특보 등 2개 상품으로 출시

사업비(손해사정 인건비)가 사실상 0에 수렴 — 소액·고빈도 회전으로 마진 확보

B. 씬파일러 유연납입

차별점: 신용점수·금융이력이 없는 고객도 청약 시 체크박스 하나로 신청 — 연체 시 해지환급금 한도 내에서 약관대출로 자동 대환되어 증권이 실효되지 않음

기존엔 놓치던 씬파일러 고객층 획득 + 약관대출 이자마진이 추가 수익원

C. 웰니스 연동 동적 보험료

차별점: 챗봇에게 건강검진 결과를 알려주면 이전 대비 위험도 개선을 자동 판정해 보험료를 실제로 온체인 할인 조정(최대 ±20%) — 포인트 리워드가 아니라 보험료 자체가 바뀜

저위험군 리텐션 상승 + 역선택 감소로 장기 손해율 개선

D. 재보험풀(외부 유동성 공급)

차별점: 외부 투자자가 예치한 지분가치가 고정 APR이 아니라 DentalInsurance의 실제 보험료 유입(ceding)에 연동 — 청구가 몰리면 지분가치가 실제로 낮아지는 진짜 리스크 공유 구조(대체투자상품과 근본적으로 다름)

자기자본 부담 없이 보험 인수 여력(underwriting capacity) 확장

E. B2B 파트너 API

차별점: 이 AI상담+온체인 조회 엔진을 소형 GA·핀테크가 API 키로 직접 호출 — 관리자 인증·키 발급/해지·사용량 계량·레이트리밋까지 포함한 완결된 라이선싱 상품

보험 인수 리스크 없이 반복적 구독/API 과금 수익(recurring revenue) — 자본 요구가 가장 낮은 모델
